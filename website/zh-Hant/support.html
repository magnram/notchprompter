Mac 版 NotchPrompter 說明。

開始使用

  1. 打開 NotchPrompter。提詞機會出現在螢幕頂端、相機下方。
  2. 按一下紅色的麥克風，並允許取用麥克風和語音辨識。
  3. 大聲朗讀你的講稿。文字會跟著你的聲音走。

將指標停在提詞機上即可看到按鈕：回到頂端、麥克風、播放、鉛筆（編輯器）和設定。

文字沒有跟著我的聲音走

  • 說話時，檢查瀏海旁邊的音量條有沒有在動。如果沒有，請在系統設定 → 聲音 → 輸入中選擇正確的麥克風。
  • 在提詞機中打開設定，檢查語音語言。選擇「自動」會使用講稿的語言。
  • 如果你脫稿了，按一下你正在讀的字。提詞機會從那裡繼續。
  • 在系統設定 → 隱私權與安全性 → 麥克風，以及 → 語音辨識中允許取用。

它要我開啟聽寫

NotchPrompter 在你的 Mac 上辨識語音，所以你的聲音絕不會離開 Mac。macOS 只在聽寫開啟時才允許這麼做：系統設定 → 鍵盤 → 聽寫。如果你不想開啟，可以選擇使用 Apple 伺服器，或在設定 → 隱私權中關閉僅在這部 Mac 上辨識語音。

要怎麼錄下自己？

將指標停在提詞機上，按一下錄影按鈕（圓圈），或按 C。3-2-1 倒數後，它會在文字跟著你的聲音走的同時，用相機和麥克風拍下你。再按一下即可停止。每一次拍攝都儲存在「影片 › NotchPrompter」中。如果也要錄下螢幕，請在設定 → 錄影中開啟同時錄製螢幕。

我在螢幕錄影中看不到提詞機

這是刻意的設計，讓觀眾看不到它。若要顯示，請在設定中關閉在螢幕共享和錄影中隱藏提詞機。

要怎麼調整大小？

拖移提詞機的左側、右側或底部邊緣，或底部的角落。文字大小可在設定彈出式視窗（滑桿按鈕）中調整，也可以按 ⌘ + 和 ⌘ −。

可以加上給自己看的備註嗎？

可以。把備註放在圓括號或方括號中，例如 (停頓) 或 [微笑]。提詞機會用較小的斜體顯示備註，語音跟隨也不會等你唸出來。你繼續往下讀，它就會直接跳過。

我的講稿在哪裡？

按一下提詞機中的鉛筆，或選擇「檔案」→「編輯講稿」。講稿會自動儲存在你的 Mac 上。若要保留一份拷貝，請在講稿上按右鍵並選擇「輸出」。

鍵盤快速鍵

先按一下提詞機，然後：

  • 空白鍵 播放或暫停
  • V 開啟或關閉語音跟隨
  • C 開始或停止錄影
  • R 回到頂端
  • ↑ ↓ 加快或放慢
  • ← → 變窄或變寬
  • E 打開編輯器
  • Esc 停止

還是沒解決？

在 GitHub 上回報問題，說明發生了什麼事。請附上你的 macOS 版本和講稿的語言。
