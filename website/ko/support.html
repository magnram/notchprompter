Mac용 NotchPrompter 도움말.

시작하기

  1. NotchPrompter를 엽니다. 화면 상단, 카메라 아래에 프롬프터가 나타납니다.
  2. 빨간색 마이크를 클릭하고 마이크 및 음성 인식 접근을 허용합니다.
  3. 대본을 소리 내어 읽습니다. 텍스트가 목소리를 따라갑니다.

프롬프터 위에 포인터를 올리면 버튼이 보입니다: 맨 위로, 마이크, 재생, 연필(편집기), 설정.

텍스트가 목소리를 따라가지 않아요

  • 말할 때 노치 옆의 막대가 움직이는지 확인하세요. 움직이지 않으면 시스템 설정 → 사운드 → 입력에서 올바른 마이크를 선택하세요.
  • 프롬프터에서 설정을 열고 음성 언어를 확인하세요. '자동'은 대본의 언어를 선택합니다.
  • 대본에서 벗어났다면 지금 읽고 있는 단어를 클릭하세요. 프롬프터가 거기서부터 이어갑니다.
  • 시스템 설정 → 개인정보 보호 및 보안 → 마이크, 그리고 → 음성 인식에서 접근을 허용하세요.

받아쓰기를 켜라고 나와요

NotchPrompter는 Mac에서 음성을 인식하므로 목소리가 Mac 밖으로 나가지 않습니다. macOS는 받아쓰기가 켜져 있을 때만 이를 허용합니다: 시스템 설정 → 키보드 → 받아쓰기. 켜고 싶지 않다면 Apple 서버 사용을 선택하거나, 설정 → 개인정보 보호에서 이 Mac에서만 음성 인식을 끄세요.

나를 녹화하려면 어떻게 하나요?

프롬프터 위에 포인터를 올리고 녹화 버튼(원)을 클릭하거나 C를 누르세요. 3-2-1 카운트다운 후, 텍스트가 목소리를 따라가는 동안 카메라와 마이크로 촬영합니다. 다시 클릭하면 정지합니다. 각 테이크는 동영상 › NotchPrompter에 저장됩니다. 화면이나 화면과 카메라를 함께 녹화하려면 설정 → 녹화의 녹화에서 선택하세요.

화면 녹화에 프롬프터가 보이지 않아요

보는 사람이 볼 수 없도록 일부러 그렇게 만들었습니다. 보이게 하려면 설정에서 화면 공유 및 녹화에서 프롬프터 가리기를 끄세요.

크기는 어떻게 바꾸나요?

프롬프터의 왼쪽, 오른쪽 또는 아래쪽 가장자리나 아래쪽 모서리를 드래그하세요. 텍스트 크기는 설정 팝오버(슬라이더 버튼)에서 바꾸거나 ⌘ + 및 ⌘ −를 누르세요.

나만 보는 메모를 넣을 수 있나요?

네. (잠시 멈춤)이나 [미소]처럼 괄호나 대괄호로 감싸세요. 프롬프터는 메모를 작은 기울임꼴로 보여 주며, 음성 따라가기는 메모를 말할 때까지 기다리지 않습니다. 계속 읽으면 그냥 지나갑니다.

대본은 어디에 있나요?

프롬프터의 연필을 클릭하거나 파일 → 대본 편집을 선택하세요. 대본은 Mac에 자동으로 저장됩니다. 사본을 보관하려면 대본을 오른쪽 클릭하고 내보내기를 선택하세요.

키보드 단축키

먼저 프롬프터를 클릭한 다음:

  • 스페이스 바 재생 또는 일시 정지
  • V 음성 따라가기 켜기 또는 끄기
  • C 녹화 시작 또는 정지
  • R 맨 위로
  • ↑ ↓ 빠르게 또는 느리게
  • ← → 좁게 또는 넓게
  • E 편집기 열기
  • Esc 정지

아직 해결되지 않았나요?

GitHub에 이슈를 등록하고 무슨 일이 있었는지 설명해 주세요. macOS 버전과 대본의 언어도 함께 적어 주세요.
