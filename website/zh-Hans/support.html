NotchPrompter
视频 功能 支持 GitHub

支持

Mac 版和 iPhone 版 NotchPrompter 帮助。

入门

  1. 打开 NotchPrompter。提词器会出现在屏幕顶部、摄像头下方。
  2. 点按红色的麦克风，并允许访问麦克风和语音识别。
  3. 大声朗读你的讲稿。文字会跟随你的声音。

将指针悬停在提词器上即可看到按钮：回到顶部、麦克风、播放、铅笔（编辑器）和设置。

文字不跟随我的声音

  • 说话时，检查刘海旁边的音量条是否在动。如果没有，请在系统设置 → 声音 → 输入中选择正确的麦克风。
  • 在提词器中打开设置，检查语音语言。选择“自动”会使用讲稿的语言。
  • 如果你脱稿了，点按你正在读的词。提词器会从那里继续。
  • 在系统设置 → 隐私与安全性 → 麦克风以及 → 语音识别中允许访问。

它要求我打开听写

NotchPrompter 在你的 Mac 上识别语音，所以你的声音绝不会离开 Mac。macOS 只在听写打开时才允许这样做：系统设置 → 键盘 → 听写。如果你不想打开它，可以选择使用 Apple 服务器，或在设置 → 隐私中关闭仅在这台 Mac 上识别语音。

如何录制自己？

将指针悬停在提词器上，点按录制按钮（圆圈），或按 C。3-2-1 倒计时后，它会在文字跟随你声音的同时，用摄像头和麦克风拍摄你。再次点按即可停止。每一条都存储在“影片 › NotchPrompter”中。如果要录制屏幕，或同时录制屏幕和摄像头，请在设置 → 录制的录制中选择。

我在录屏中看不到提词器

这是有意为之，为了不让观众看到。如需显示，请在设置中关闭在屏幕共享和录制内容中隐藏提词器。

如何调整大小？

拖移提词器的左边缘、右边缘、下边缘或底部角落。文字大小可在设置弹出菜单（滑块按钮）中调整，也可以按 ⌘ + 和 ⌘ −。

可以给自己加备注吗？

可以。把备注放在圆括号或方括号里，例如 (停顿) 或 [微笑]。提词器会用较小的斜体显示它们，语音跟随不会等你读出它们。你继续往下读，它就会跳过去。

我的讲稿在哪里？

点按提词器中的铅笔，或选取“文件”→“编辑讲稿”。讲稿会自动存储在你的 Mac 上。如需保留副本，请右键点按讲稿并选取“导出”。

键盘快捷键

先点按提词器，然后：

  • 空格键 播放或暂停
  • V 打开或关闭语音跟随
  • C 开始或停止录制
  • R 回到顶部
  • ↑ ↓ 加快或减慢
  • ← → 变窄或变宽
  • E 打开编辑器
  • Esc 停止

iPhone 版 NotchPrompter

选择一篇讲稿，然后轻点在提词器中打开。讲稿会显示在屏幕顶部、前置摄像头下方。轻点麦克风让讲稿跟随你的声音，或选择滚动并轻点播放。Aa 按钮用于设置文字大小和速度。红色按钮用于录制一条录像，录像会存储到“照片”中。

iPhone 版有哪些功能免费？如何恢复购买？

滚动模式、编辑器和练习讲稿始终免费。使用你自己的讲稿时，可以免费进行 3 次带声音跟随的录制。之后只需一次性购买，即可解锁全部功能。无需订阅。如果你之前已购买，请用同一个 Apple 账户登录，打开设置（齿轮图标），然后轻点恢复购买。

还是没解决？

在 GitHub 上提交问题，描述发生了什么。请附上你的 macOS 或 iOS 版本和讲稿的语言。
