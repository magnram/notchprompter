Mac用NotchPrompterのヘルプ。

はじめに

  1. NotchPrompterを開きます。画面の上部、カメラの下にプロンプターが表示されます。
  2. 赤いマイクをクリックし、マイクと音声認識へのアクセスを許可します。
  3. 原稿を声に出して読みます。文字が声に合わせて進みます。

プロンプターにポインタを重ねるとボタンが表示されます：先頭に戻る、マイク、再生、鉛筆（エディタ）、設定。

文字が声についてこない

  • 話したときに、ノッチの横のバーが動くか確認してください。動かない場合は、システム設定 → サウンド → 入力で正しいマイクを選んでください。
  • プロンプターの設定を開き、音声の言語を確認してください。「自動」にすると、原稿の言語が選ばれます。
  • 原稿から外れたときは、今読んでいる単語をクリックしてください。そこからプロンプターが続きを進めます。
  • システム設定 → プライバシーとセキュリティ → マイク、および → 音声認識でアクセスを許可してください。

音声入力をオンにするよう求められる

NotchPrompterは音声をMac上で認識するので、あなたの声がMacの外に出ることはありません。macOSでこれができるのは、音声入力がオンのときだけです：システム設定 → キーボード → 音声入力。オンにしたくない場合は、Appleのサーバを使用を選ぶか、設定 → プライバシーでこのMac上でのみ音声を認識をオフにしてください。

自分を録画するには？

プロンプターにポインタを重ねて録画ボタン（丸）をクリックするか、Cを押します。3-2-1のカウントダウンのあと、文字が声に合わせて進むあいだ、カメラとマイクであなたを撮影します。もう一度クリックすると停止します。各テイクは「ムービー › NotchPrompter」に保存されます。画面も録画するには、設定 → 録画で画面も収録をオンにしてください。

画面収録にプロンプターが映らない

見ている人に見えないよう、意図的にそうしています。表示するには、設定で画面共有と収録でプロンプターを非表示にするをオフにしてください。

サイズを変えるには？

プロンプターの左端、右端、下端、または下の角をドラッグします。文字サイズは設定ポップオーバー（スライダのボタン）で変更するか、⌘ +と⌘ −を押します。

自分用のメモを入れられますか？

はい。(間)や[笑顔]のように、丸かっこや角かっこで囲んでください。プロンプターでは小さな斜体で表示され、音声追従はメモが読まれるのを待ちません。読み進めれば、そのまま通り過ぎます。

原稿はどこにありますか？

プロンプターの鉛筆をクリックするか、ファイル → 原稿を編集を選びます。原稿はMacに自動で保存されます。コピーを残すには、原稿を右クリックして「書き出す」を選びます。

キーボードショートカット

まずプロンプターをクリックしてから：

  • スペース 再生または一時停止
  • V 音声追従のオン/オフ
  • C 録画の開始または停止
  • R 先頭に戻る
  • ↑ ↓ 速く/遅く
  • ← → 幅を狭く/広く
  • E エディタを開く
  • Esc 停止

まだ解決しませんか？

GitHubでIssueを作成し、何が起きたかを書いてください。macOSのバージョンと原稿の言語も添えてください。
