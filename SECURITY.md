# Security

## Report a problem

Please don't report security problems in public Issues.

Report them privately on GitHub instead: open the **Security** tab of this repository and click
**Report a vulnerability**. Only the maintainer can see the report.

Tell me:

- what the problem is, and what someone could do with it
- the steps to see it happen
- your macOS version and the NotchPrompter version (NotchPrompter › About NotchPrompter)

NotchPrompter is a hobby project, so a reply can take a few days. When a fix is out,
I will say thanks in the release notes, unless you'd rather stay anonymous.

## Supported versions

Only the newest version, on the Mac App Store and on the `main` branch, gets fixes.

## What counts

The app has access to your microphone, camera, screen and script files, so these matter most:

- audio, video, scripts or transcripts that leave your Mac when they shouldn't
- speech sent to Apple's servers while **Recognise speech on this Mac only** is on
- the prompter showing up in screen sharing, screenshots or recordings while it is set to be hidden
- the microphone or camera staying on after you stop
- files read or written outside the folders you picked

Bugs that don't touch your data or privacy are welcome in [Issues](https://github.com/magnram/notchprompter/issues).
